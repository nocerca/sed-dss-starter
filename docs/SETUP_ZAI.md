# Третий backend: Z.AI с бесплатной GLM-4.7-Flash

Задача `T11`, проверка источников 25.10.2026. Варианты `yandex` и `gigachat` сохранены; добавлен `MODEL_BACKEND=zai`. Маршрут: API -> изолированный OpenClaw -> официальный API Z.AI. Прямого обращения из основного API к модели нет.

## Почему выбран этот вариант

- В [официальном прайсе Z.AI](https://docs.z.ai/guides/overview/pricing) `glm-4.7-flash` и `glm-4.5-flash` указаны как Free для входа и выхода. Это стоимость конкретных моделей, не обещание безлимитного или вечного доступа.
- Стандартный API совместим с Chat Completions; [официальная инструкция](https://docs.z.ai/guides/overview/quick-start) предусматривает создание Standard API Key. Платная подписка Coding Plan для выбранного подключения не требуется.
- С компьютера проекта проверены HTTPS-соединения: страница ключей отвечает 200, `/api/paas/v4/models` отвечает 401 без ключа. Это подтверждает сетевую достижимость, но не заменяет проверку зарегистрированного аккаунта, его региональных условий и модельного запроса. Гарантии работы для любого провайдера связи в РФ не заявляются.
- Это зарубежный провайдер: наличие доступа из РФ не означает хранение данных в РФ. Пока используются только разрешённые синтетические документы; двойное согласие сохранено.

## Что сделать владельцу аккаунта

1. Откройте [страницу API-ключей Z.AI](https://z.ai/manage-apikey/apikey-list), зарегистрируйтесь или войдите.
2. Создайте **Standard API Key**. Не покупайте Coding Plan и не пополняйте баланс ради этой инструкции. Если кабинет требует оплату/не даёт доступ к Flash, остановитесь: успешная регистрация и бесплатный доступ вашего аккаунта пока не подтверждены.
3. Скопируйте ключ в локальный `.env`; в чат его присылать не нужно.
4. Добавьте или измените строки:

```dotenv
MODEL_BACKEND=zai
ZAI_API_KEY=ваш_Standard_API_Key
ZAI_MODEL=glm-4.7-flash
LLM_PROVIDER=openclaw
ALLOW_EXTERNAL_LLM=true
LLM_TIMEOUT_SECONDS=150
```

`LLM_PROVIDER` всегда указывает на OpenClaw. Значение `zai` задаётся только в `MODEL_BACKEND`. Endpoint закреплён: `https://api.z.ai/api/paas/v4`; подставлять адрес сайта, BigModel или Coding Plan не нужно. Разные платформы могут иметь разные ключи.

## Запуск и проверка

В PowerShell из корня проекта:

```powershell
python scripts/setup_local.py
docker compose config --quiet
docker compose run --rm -e OPENCLAW_VALIDATE_ONLY=1 openclaw
docker compose up -d --build
python scripts/smoke_test.py
python scripts/smoke_test.py --llm
```

Обычный smoke-тест не использует модель. Флаг `--llm` — явное согласие отправить через OpenClaw только встроенное синтетическое письмо. Скрипт не читает ваши письма и не печатает ключи. Для успешного модельного теста нужны `mode=hybrid`, `provider=openclaw`, `status=completed`; `partial` не считается успешным подключением.

Общий запуск, внутренние токены и хранение данных описаны в [SETUP.md](SETUP.md). Ключ Z.AI не является ключом основного API или токеном OpenClaw.

## Ограничения и ошибки

- Разрешены только `glm-4.7-flash` и `glm-4.5-flash`. Платные `glm-4.7`, `glm-4.7-flashx`, GLM-5 и автоматические маршрутизаторы отклоняются конфигурацией. Автоматического перехода на другую модель нет.
- Точные лимиты смотрите в [кабинете Z.AI](https://z.ai/manage-apikey/rate-limits). Ошибки 429 могут означать ограничение или перегрузку; результаты локальных правил сохраняются.
- Ошибка 401 при модельном запросе требует проверки ключа и стандартного endpoint. Нулевая цена в прайсе сама по себе не доказывает наличие доступа у аккаунта.
- Основной API не получает `ZAI_API_KEY` через Compose: секрет передаётся только OpenClaw. Он не добавляется в образ, тестовые фикстуры или отчёты.
- Состояние и кэш OpenClaw находятся в `tmpfs`. Это не обещание немедленного удаления транскрипта после ответа или нулевого хранения у внешнего провайдера.
- Реальные запросы с ключом владельца проверены 25.10.2026: `hybrid / completed`, примерно 11 и 93 секунды на встроенном синтетическом письме. Это отдельные наблюдения, не измерение качества или гарантия задержки; соответствие ГОСТ не заявляется.

В конфигурации Z.AI явно передаётся `thinking: {type: "disabled"}` через `params.extra_body`: при отключённых плагинах одного `thinkingDefault=off` оказалось недостаточно. До исправления реальный ответ исчерпывал 1600 токенов на рассуждения без итогового текста. Для медленных ответов шлюзу отведено до 120 секунд, API — 150 секунд; smoke-клиент ждёт до 180 секунд. Параметр отключения описан в [документации Z.AI](https://docs.z.ai/guides/capabilities/thinking-mode), передача extra_body — в [документации OpenClaw](https://docs.openclaw.ai/providers/zai).

Использование через готовые запросы: [Postman](POSTMAN.md).

## Переключение между тремя вариантами

| Значение MODEL_BACKEND | Какие настройки нужны |
|---|---|
| `yandex` | `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_MODEL` |
| `gigachat` | `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE`, `GIGACHAT_MODEL`, внутренний `MODEL_BRIDGE_API_KEY`; запуск с `--profile gigachat` |
| `zai` | `ZAI_API_KEY`, `ZAI_MODEL=glm-4.7-flash` |

После смены backend пересоздайте OpenClaw: `docker compose up -d --force-recreate openclaw`. После смены `LLM_PROVIDER`/`ALLOW_EXTERNAL_LLM` пересоздайте также API. Отключение модели: `LLM_PROVIDER=none`, `ALLOW_EXTERNAL_LLM=false` и пересоздание API.
