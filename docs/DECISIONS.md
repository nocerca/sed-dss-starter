# Принятые решения

## Подтверждено

- Обрабатываются только исходящие письма. Решение остаётся у автора; отправка и изменение оригиналов отсутствуют.
- OpenClaw — обязательный изолированный слой LLM по требованию пользователя. Правила не зависят от доступности шлюза. Прямой обход шлюза запрещён.
- Ollama и модели Llama не используются. Причина отдельного запрета Llama не уточнена; разрешения его снять нет.
- Яндекс и GigaChat сохранены. Пользователь разрешил третий вариант: Z.AI, стандартный API, только `glm-4.7-flash`/`glm-4.5-flash`, без платного fallback.
- Источники `good/bad` не являются нормативными. В реестре пять эвристик и 16 проверок/диагностик профиля инструкции; версии и область применимости фиксируются. Тип источника `instruction` означает предоставленный организационный документ, `verified=false` не подменяет экспертное подтверждение. Старые версии и отчёты не переписываются.
- Профиль `office_instruction_letters` выбирается явно отдельным полем, автоматически организация не угадывается. Реализованная часть каталога выполняется локально. Неизвестные свойства/роли дают недостаток данных; проверка геометрии и полномочий отложена. Комментарии сотрудника и образцы не отменяют разрешённые инструкцией варианты: словесную дату, диапазон кегля, отдельные размеры реквизитов. Привязка источника, инвентаризация и предварительные результаты 41 письма хранятся только локально; внешней передачи не было.
- Десять демонстрационных дефектов созданы на синтетическом письме, без заимствования частного текста. У каждой правки есть селектор, исходное/новое значение и ожидаемый код; два допустимых контроля защищают от ложных срабатываний. Это техническая проверка, не измерение экспертной точности.
- Поиск — пересечение слов. Эмбеддинги, BM25 и научные измерения не добавляются до проверки baseline на размеченном корпусе.
- API синхронный. Идемпотентность хранится в PostgreSQL, сырой ключ и открытый хеш письма не сохраняются. После неопределённого исхода запрос не повторяется автоматически.
- v0.6: для повторных успешных запусков модели/LanguageTool добавлен кэш ссылок на отчёты в памяти процесса, TTL 900 секунд и LRU 128 записей. Авторизация/согласие предшествуют кэшу; ключ включает входы, конфигурацию, правила и базу знаний. Файлы и результаты не дублируются в кэше, partial/processing не сохраняются. Новый расчёт — use_cache=false с новым ключом операции. Redis пока не требуется; одновременный дубль другого ключа получает 409/busy, межпроцессная гарантия остаётся у идемпотентности.
- Миграции аддитивные, автоматическое разрушительное downgrade запрещено. Рабочая БД обновляется после резервного копирования.
- В логах нет содержимого и идентификаторов писем: access log API выключен, вывод агента подавляется. Трассировка доступна через `X-Request-ID` и локальные отчёты.
- История шлюза временная в `tmpfs`, а не постоянный том; мгновенное удаление транскрипта не заявляется. Секрет модели получает только соответствующий контейнер.
- Начальный языковой модуль — локальный LanguageTool 6.6 с явным флагом запроса, без облачного API и сетевого обхода. Его дистрибутив берётся из указанного самим проектом community Docker-образа, закреплённого digest; наш runtime не имеет внешней сети.
- Жанр оценивается только по эвристическим признакам версии 1.0.0, без вероятностей и автоматического отказа. Сведения о картинках означают наличие OOXML-ссылок, не понимание их содержимого.
- Недоказуемые по тексту отсутствие/визуальное оформление/нормативность и цитаты из одних заголовков отбрасываются. Это консервативные эвристики; эффективность и полнота ждут корпусной валидации.

## Требуется уточнить

Конкретная СЭД и её API, утверждённые корпоративные шаблоны и применимость редакции предоставленной инструкции, поставщик SSO/ролей, политика хранения реального корпуса, разрешение его внешней обработки, экспертная рубрика. Весов общей оценки и результатов эксперимента пока нет.

## Источники, проверенные 25.10.2026

- [OpenClaw HTTP API](https://docs.openclaw.ai/gateway/openai-http-api): это агентный запуск, ограничения задаются конфигурацией, а не только prompt.
- [OpenClaw Docker](https://docs.openclaw.ai/install/docker): официальный образ; в проекте закреплена версия `2026.9.3`.
- [Z.AI Pricing](https://docs.z.ai/guides/overview/pricing), [Standard API Key](https://docs.z.ai/guides/overview/quick-start): Flash-модели указаны как Free; реальная доступность аккаунта проверяется отдельно.
- [Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/), [пробный период](https://yandex.cloud/ru/docs/getting-started/free-trial/concepts/quickstart): описания гранта противоречат друг другу; бесплатная квота не гарантируется.
- [GigaChat для физлиц](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs): условия зависят от статуса клиента; общий бесплатный доступ новым аккаунтам не обещается.
- [Отключение логирования у Яндекса](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/disable-logging): добавлен соответствующий заголовок.
- [Локальный сервер LanguageTool](https://dev.languagetool.org/http-server), [архив 6.6](https://languagetool.org/download/), [перечень community Docker-образов в репозитории проекта](https://github.com/languagetool-org/languagetool#docker): локальный базовый сервер не включает облачные AI-правила.

Достижимость сайта или 401 без ключа доказывает только сетевую связь. Она не подтверждает выдачу квоты, региональные условия аккаунта, качество анализа или успешную генерацию.
