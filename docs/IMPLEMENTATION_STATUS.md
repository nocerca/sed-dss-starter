# Текущий статус v0.8

Обновлено 04.11.2026. Веб-интерфейс — `/`, интеграционный FastAPI REST — `/api/v1`, Swagger и Postman доступны независимо. PostgreSQL хранит отчёты и версии правил, OpenClaw — обязательный изолированный маршрут к модели, LanguageTool — отдельный локальный языковой сервис.

## Реализовано

- **T24 / помощник:** в карточке «Разобрать замечание» — локальные explain/fix по исторической RuleVersion, необязательное уточнение моделью, question/rephrase через OpenClaw. Отдельный REST `/api/v1/reports/{report_id}/assistant`, Swagger и папка 08 Postman. Вопрос до 1000, фрагмент до 2000 символов; полного документа/истории нет. Rephrase — отдельное редакторское задание только по selected_text, без повторной оценки старой цитаты и без нормативных ссылок. Ответы проходят схему/источники/технический контроль цифровых токенов, не семантическую экспертизу. [Контракт](ASSISTANT.md).

- **T23 / веб-интерфейс:** загрузка/перетаскивание DOCX, профиль инструкции и дополнительные проверки, карточки замечаний/категории, раскрываемые предупреждения и журнал исходов, JSON-выгрузка, история с пагинацией, поиск правил, светлая/тёмная тема и мобильная раскладка. Полупрозрачная верхняя панель, без внешних ресурсов и отдельного frontend-сервера. Ключ в RAM вкладки, только тема в localStorage, модель выключена по умолчанию; согласие расходуется до каждого Send. Повтор после неопределённого ответа сохраняет ключ операции. [Использование](WEB.md).

- Для повторных успешных запросов модели/LanguageTool — кэш ссылок на отчёты в памяти процесса: TTL 900 с, LRU 128, без Redis и без копий исходников/ответов модели. Analysis-Cache=hit/miss/bypass, 409/busy при активном дубле. Новое вычисление — use_cache=false с новым ключом операции. Авторизация/согласие до кэша; инвалидация по входам/правилам/конфигурации/базе и удалению отчёта. [Контракт и замеры](CACHE.md).

- Локальные замечания содержат фактическое/ожидаемое значение, место и конкретное действие. В results профиля также есть message/recommendation. Причины недостатка данных указывают блок/свойство; картинки/поля Word дают предупреждение только при обнаружении. LanguageTool различает причины сбоя без раскрытия технического ответа. Старые отчёты сохраняются; новые формулировки появляются при новом анализе.

- Пять эвристик без выбора профиля; 16 проверок/диагностик инструкции при явном policy_profile=office_instruction_letters. Поля, шрифты/размеры, абзацный отступ, проверяемая часть интервалов, дата, контакт исполнителя и подпись. [Точная применимость](RULES.md), [полный каталог](LETTER_POLICY.md).
- Роли блоков выделяются консервативно по текстовым признакам. Неизвестное свойство или роль даёт insufficient_data. В metrics.policy_checks сохранены исходы, ожидаемое/наблюдаемое и основания. До 2000 результатов/200 замечаний; при усечении partial. Pass относится к проверенным свойствам, не всему реквизиту/документу.
- DOCX: таблицы, определённые колонтитулы, inline smartTag/content controls, кэш полей, runs, наследование стилей и часть свойств абзацев/разделов. Инструкции/ссылки не выполняются. Полная визуальная раскладка, темы и все способы вёрстки не вычисляются.
- Локальный LanguageTool 6.6 по use_language_checks=true: начальная орфография, часть грамматики/пунктуации, до 20 000 единиц UTF-16. Без внешней сети и публичного API. Сбой даёт partial с сохранением правил.
- OpenClaw, взаимозаменяемые Яндекс/GigaChat/Z.AI, двойное согласие на каждый внешний запрос, консервативный фильтр модельных замечаний и замеры этапов. Реальный Z.AI / GLM-4.7-Flash проверен на синтетическом письме 25.10.2026; новые реальные вызовы в этом этапе не выполнялись. Яндекс/GigaChat ждут отдельных live-проверок.
- Авторизация ключом, метаданные СЭД, трассировка, идемпотентность, чтение/список/удаление отчётов, версии правил, база знаний DOCX/TXT и поиск по словам. Реестр letters-0.5.0, Alembic 0003: аддитивная таблица assistant_operations с HMAC/статусом/ограниченным ответом. Вопрос и вставленный текст отдельно не сохраняются; ответ может их содержать. Delete/retention отчёта очищает ответы и ссылки, маркеры остаются для 410. Исторические отчёты/версии не переписываются.

## Документы и воспроизводимость

- Созданы десять искусственных дефектных DOCX и два допустимых контроля в examples/private/postman_cases. Исходные письма не использовались. Manifest содержит селектор и единственное контролируемое изменение. [Проверка в Postman](POSTMAN.md#десять-документов-с-ошибками).
- scripts/create_letter_demos.py воспроизводит пакет; scripts/check_letter_demos.py проверяет его через REST. В коллекции есть десять готовых запросов с проверкой ожидаемого кода; ключи пользователя не включены.
- Все 41 исходное письмо прочитаны локально без ошибок разбора; хеши совпали. Предварительные результаты — examples/private/policy/preliminary_checks.json, статус unreviewed. Это не экспертная разметка или научное измерение; внешней передачи не было.
- Оригиналы, инструкция, локальные отчёты, секреты, backups, окружение, настройки IDE и кэши исключены из Git/Docker. Публикуются код и синтетический генератор. Проверка scripts/check_release.py читает staged-содержимое и отказывает при частных артефактах/настроенных секретах.
- Документация сведена к действующему поведению; завершённое — CHANGELOG.md, оставшаяся работа — TASKS.md. Старые .wheelhouse/build, sample_letter.docx и кэши остались после ранее отклонённого удаления и не публикуются. .venv и используемые метаданные установки сохраняются.

- **211 Python-тестов и 21 Node-тест**: локальные ответы, историческая версия, отсутствующее основание, строгие поля/примеры Swagger, двойное согласие даже при replay, отсутствие метаданных в payload, отдельные сессии, ложные ссылки/числа, описание фактического изменения формулировки, ошибки, конкуренция, delete/retention и удаление отчёта во время ожидания. Ruff и Compose config/сборка прошли; живой OpenAPI v0.8.0 совпал со снимком. Сохранилось прежнее предупреждение Starlette/TestClient о httpx.
- Изолированный Chromium: корректный/неверный ключ, отключённые модули, неверный файл, настоящий синтетический DOCX и профиль, фильтр исходов, JSON, история/правила, мобильный экран/тема, согласие на каждый Send, сохранение partial, безопасный вывод HTML-подобных строк, повтор после потери ответа, отсутствие ключей/отчётов в browser storage и внешних браузерных запросов. Модельные ответы в браузерных сценариях имитированы; внешний провайдер отключён.
- На основном адресе Docker через настоящий браузер выполнены локальный анализ синтетического DOCX и помощь по замечанию: историческое основание профиля и шаги Word. Отдельно прошли health/REST smoke с LanguageTool, сохранение/чтение и 12 синтетических дефектов/контролей. Настоящий изолированный OpenClaw с тестовой моделью прошёл REST/БД/consent/конкурентный ключ/удаление для помощника; журнал не содержит тестовых маркеров. Рабочая БД не использовалась этим изолированным тестом.
- На синтетическом русском тексте реальный вопрос и rephrase через настроенный OpenClaw/Z.AI дали HTTP 200; повтор по ключу вернул прежний ответ, отказ без согласия сохранился, исходный отчёт не изменился. Принятая формулировка убрала разговорное «значит», сохранила дату 24.12.2025 и количество 12. Эти отдельные запросы заняли 65,45 и 7,2 с, были и отклонения ответа/таймаут шлюза 120 с. Это не статистика и не гарантия доступности/качества. Один промежуточный прогон с ошибочной кодировкой PowerShell исключён из доказательства русской переформулировки и повторён с UTF-8. Ошибочный ответ не принимается, автоматического обхода нет. Частные письма модели не передавались.
- Перед обновлением API сделана резервная копия PostgreSQL в custom-формате; архив проверен pg_restore --list. Данные и настроенные ключи не выводились.
- На этом обновлении подключения API к двум Docker-сетям сохранились; БД/тома не пересоздавались. Предыдущие случаи потери сети локальным Compose описаны в CHANGELOG.md.
- Предыдущие проверки кэша/настоящего изолированного OpenClaw с тестовой моделью и контрольный замер 475,91 → 16,90 мс описаны в CACHE.md/CHANGELOG.md. Реальный Z.AI проверен 25.10.2026. Это технические сценарии, не научная оценка качества/скорости.

## Ограничения

Нет полного соответствия инструкции/ГОСТ, экспертно измеренной точности, полной языковой/логической экспертизы, OCR, физических координат страниц, семантического RAG, SSO/ролей и адаптера конкретной СЭД. Остальные требования каталога ждут реализации/данных/согласованного рендерера. Внешние вызовы требуют отдельного согласия; tmpfs шлюза не гарантирует немедленного удаления после ответа или нулевого хранения у провайдера. Общего балла качества нет.
