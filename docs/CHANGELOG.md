Рендеринг, все способы вёрстки и полномочия не подтверждаются.
- **T08:** `policy_profile` в multipart и идемпотентности; структурные expected/observed/applicability_reason у замечания; исходы/основания/счётчики в metrics.policy_checks. Ограничения 2000 результатов/200 замечаний, partial при усечении. Swagger/OpenAPI и Postman обновлены.
- **T06:** реестр letters-0.5.0 с пятью эвристиками и 16 проверками профиля. Исправлены повреждённые русские описания; версии эвристик увеличены до 1.0.1. Условие `policy_profiles` и тип источника `instruction` отделяют предоставленную инструкцию от эвристик и экспертно подтверждённых норм. Предыдущие спецификации и отчёты не переписываются, новая миграция схемы не нужна.
- **T09:** воспроизводимые 10 дефектных синтетических DOCX и два допустимых контроля, manifest с отдельными изменениями/ожидаемыми кодами. Папка 06 Postman содержит готовые запросы и автоматические проверки кодов. Добавлен REST smoke всего пакета.
- **T09:** все 41 оригинал разобраны локально без ошибок; хеши совпали, предварительные замечания сохранены приватно со статусом unreviewed. Экспертная точность не измерялась; реальные документы и инструкция не передавались моделям.
- **T21:** документация приведена к фактической реализации; локальные настройки IDE, архивы/дампы, кэши и частные документы исключены из публикации. Добавлены проверка staged-файлов/настроенных секретов перед отправкой и GitHub Actions для тестов. Рабочие настройки, оригиналы, окружение и БД сохранены.
- Удаление сгенерированных кэшей через PowerShell отклонено автоматической политикой (blocked by policy); кэши сохранены и исключены из Git/Docker. Потерянное подключение API к внутренней сети language восстановлено пересозданием только API; локальный языковой smoke повторно прошёл.
- Проверено: 152 Python-теста, 11 Node-тестов, Ruff для изменённых Python-файлов, конфигурация/сборка Compose, соответствие живого OpenAPI снимку, 12 синтетических документов через REST и изолированный настоящий OpenClaw с тестовой моделью. Перед обновлением API создан и проверен архив PostgreSQL. Реальная внешняя модель в этом этапе не вызывалась.

## 01.11.2026 — спецификация правил по инструкции

- **T07 / подготовительная часть T06:** локально прочитана глава III; составлен профиль из 53 позиций: 39 требований к оформлению/реквизитам, 6 языковых групп и 8 спорных предложений. У каждой позиции есть область применения, доказательство, ограничения и ссылки на источник. `config/letter_policy.json` и `docs/LETTER_POLICY.md` — спецификация; нормативные проверки ещё не активированы в API.
- **T09, подготовка:** инвентаризировано 41 письмо с меткой `unreviewed`; зафиксирован протокол разметки и контролируемых изменений. Оригиналы не изменены, реальные документы не передавались модели. Пути/хеши и привязка исходника находятся в игнорируемой локальной папке.
- **T05, исправление извлечения:** сохранённый текст внутри Word smartTag, встроенных content controls и простых полей теперь читается вместе с форматированием. Это позволило извлечь пропускавшийся отступ 1,25 см из инструкции. Инструкции полей/ссылки не исполняются; рекурсивная вложенность ограничена.
- `.gitignore` закрывает вложенные пользовательские документы и все производные материалы в examples; исключения оставлены только для README и синтетического Postman DOCX. Docker по-прежнему исключает всю папку examples.
- Проверено: 134 Python-теста, 11 Node-тестов, Ruff для изменённых Python-файлов и конфигурация Compose. Контрольные хеши 41 письма и инструкции совпали после работы; оригиналы сохранены.
- Docker пересобран; REST smoke без модели и с локальным LanguageTool прошли. На синтетическом тексте найдены две языковые ошибки, отчёт completed/provider=none. После старта Docker восстановлено подключение API к внутренней сети language пересозданием только API. Реальная модель повторно не вызывалась.

## 0.3.0 — 25.10.2026

- **T08, Swagger:** русские группы операций, назначение всех параметров форм/заголовков/пути/фильтров, полей отчёта, замечаний и метрик; пояснения режима/статуса/verified, согласия и ограничений обработки изображений; синтетические примеры трёх исходов и описания ошибок. - **T11, проверка с ключом:** реальный Z.AI / GLM-4.7-Flash через OpenClaw вернул завершённый гибридный отчёт на синтетическом письме. Явно отключены provider thinking через extra_body и увеличены таймауты после обнаруженных ошибок. Mock-проверка контролирует фактический провайдерский параметр.
- **T08, клиент:** импортируемые коллекция/окружение Postman без секретов, синтетический DOCX и инструкция. Внешний анализ и удаление требуют отдельного включения; добавлены проверки контракта и отсутствия секретов.
- **T06:** типизированный реестр всех пяти эвристик, версии и область применимости, неизменяемые спецификации в БД. Формальные нормативные проверки не добавлены без источников.
- **T06:** Alembic вместо `create_all`, принятие совместимой прежней схемы, аддитивное расширение; резервная копия рабочей БД до обновления.
- **T08:** идентификатор документа СЭД, тип/шаблон, трассировка, идемпотентность и защита параллельного дубля; список/удаление отчётов и опубликованный OpenAPI.

- **T11:** третий backend Z.AI с allowlist бесплатных Flash-моделей, без платного fallback; необязательные короткие повторы только 429.
- **T12/T13:** проверка цитат и источников, отдельная Docker-проверка настоящего шлюза, изоляции сессий и журналов. Устранена печать ответов дочерним процессом OpenClaw.
- **T18, локальная часть:** явная очистка отчётов, dry run по умолчанию, сохранение маркеров идемпотентности; корпус не удаляется.
- Документация сведена к текущим требованиям, инструкции, контракту, результатам и оставшимся задачам.
