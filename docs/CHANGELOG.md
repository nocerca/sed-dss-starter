# Изменения

## 0.7.0 — 04.11.2026

- **T23:** веб-интерфейс `/` в стиле GitHub: перетаскивание DOCX, явный профиль инструкции, дополнительные языковые/модельные проверки, карточки замечаний с фильтрами, раскрываемые ограничения и исходы, JSON-выгрузка, история по 20 записей и реестр правил с поиском. Светлая/тёмная тема, адаптивная раскладка, glass-эффект панели и уменьшение движения по настройке ОС.
- HTML/CSS/ES modules обслуживаются FastAPI с того же origin, поставляются в пакете и Docker. Нет CDN, npm-сборки, frontend-runtime, новых миграций или обязательных REST-параметров. `/api/v1`, Swagger и Postman остаются независимыми интерфейсами. Исправлен зависящий от Windows MIME тип `.mjs`, чтобы браузер не блокировал модули.
- Ключ вводится вручную, только в RAM вкладки; localStorage содержит только тему. Отчёты выводятся текстом, CSP запрещает inline/внешние ресурсы. Модель выключена по умолчанию; согласие сбрасывается перед каждым Send. При потере ответа неизменная форма сохраняет Idempotency-Key; автоматических повторов нет. Отключение убирает ключ и открытые отчёты из состояния клиента.
- **Проверено:** 176 Python-тестов, 17 Node-тестов, Ruff, Chromium в изолированном сценарии (вход, DOCX, JSON, история/правила, мобильная тема, XSS, consent/partial и неопределённый повтор). На рабочем Docker адресе браузер прошёл синтетический DOCX с профилем и LanguageTool без модели. Health/REST и 12 дефектов/контролей прошли; живой OpenAPI v0.7.0 совпал со снимком. Добавлен browser job GitHub Actions.
- Перед обновлением проверен backup PostgreSQL; схема/данные сохранены. У локального Docker при recreate потерялось подключение API к сети БД, восстановлено штатным подключением и перезапуском только API; после этого smoke прошёл. Реальные письма и внешний провайдер не использовались.
- Вопросы по замечаниям согласованы следующим этапом **T24**, не объявлены готовыми. [Использование интерфейса](WEB.md).

## 0.6.0 — 04.11.2026

- **T22:** проанализированы тайминги сохранённых отчётов. Для повторных тяжёлых запросов добавлен кэш HMAC → ID успешного отчёта в памяти процесса: TTL 900 с, LRU 128, без Redis/миграций и без копий исходников/результатов. Первый запуск не ускоряется, быстрые правила не кэшируются.
- **T08/T22:** use_cache=true по умолчанию, Analysis-Cache=hit/miss/bypass, 409/busy для параллельного дубля другого ключа. На hit прежние id/created_at/request_id/метрики; новые ключи идемпотентности связываются с этим отчётом. False обходит чтение/запись, старые ключи по-прежнему защищены идемпотентностью. Все приватные REST-ответы no-store.
- Ключ учитывает файл/параметры/метаданные, авторизационную область, приложение/правила, конфигурацию языка/моделей и базу знаний. Согласие и авторизация проверяются до кэша. Partial/processing и исключения не кэшируются; удалённые отчёты не восстанавливаются. Ошибка БД при связывании alias возвращает безопасный 503 без SQL/параметров и без нового модельного запуска.
- API получает только несекретные идентификаторы бэкенда/моделей; секреты провайдера остаются в шлюзе/мосте. Смену модели/ключа/конфигурации шлюза сопровождать пересозданием API и шлюза. Кэш не является распределённой блокировкой или гарантией однократного исполнения провайдером после аварии.
- В Postman добавлены use_cache и папка 07 с тремя локальными запросами miss/hit/bypass. Swagger/OpenAPI и документация обновлены; для независимых измерений требуется обход кэша.
- Проверено: 174 Python-теста, 11 Node-тестов, Ruff, Compose, совпадение живого OpenAPI v0.6.0, изолированный настоящий OpenClaw с тестовой моделью. На одном синтетическом REST-запуске LanguageTool: miss 475,91 мс, hit 16,90 мс, bypass 445,20 мс. Это наблюдение, не статистический результат. Реальная внешняя модель не вызывалась.

## 0.5.1 — 04.11.2026

- **T08 — конкретные локальные сообщения:** замечание указывает место, неверное свойство, фактическое/ожидаемое значение и отдельное действие. - LanguageTool различает таймаут, недоступность соединения, HTTP-ошибку и некорректный ответ; технические ответы, адреса и секреты не раскрываются. Эвристики показывают найденную фразу, длину абзаца/порог или список шрифтов вместо общей рекомендации.

- Проверено: 162 Python-теста, Ruff, Compose config/сборка, совпадение живого OpenAPI v0.5.1 со снимком, 10 дефектов и 2 контроля через REST, локальный LanguageTool.
