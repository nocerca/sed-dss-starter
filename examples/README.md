# Примеры

`postman_synthetic.docx` — искусственное короткое письмо для Postman. Воссоздаётся командой `python scripts/export_postman.py`, если отсутствует; существующий файл не перезаписывается.

Пользовательские DOCX в этой папке исключены из Git и Docker. Они не являются размеченным корпусом и не загружаются в базу знаний автоматически. Сохраняйте только разрешённые материалы. Произвольная лабораторная работа не заменяет пример исходящего письма.

Предоставлены 41 письмо и инструкция. Письма пока `unreviewed`, включая внешне корректные. Каталог требований опубликован в [docs/LETTER_POLICY.md](../docs/LETTER_POLICY.md). Локальные привязка источника и инвентаризация находятся в `private/policy/`; эти производные данные также исключены из Git/Docker. Оригиналы не изменяются, внешняя передача не разрешена фактом размещения в папке.

`python scripts/create_letter_demos.py` создаёт `private/postman_cases/`: десять синтетических некорректных DOCX, два допустимых контроля, manifest и README. Готовые запросы — папка 06 коллекции Postman; [инструкция](../docs/POSTMAN.md#десять-документов-с-ошибками). `python scripts/check_letter_demos.py` проверяет пакет через локальный REST без модели. Генерируемые файлы не публикуются; воспроизводится только синтетический генератор.
